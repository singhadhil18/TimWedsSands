# Tim & Sandipa — Wedding e-invite

Static site (no build step). Edit `assets/js/config.js` for names, dates, events, venue, RSVP and photos.

Personalised links: `https://<domain>/?to=The%20Naidoo%20Family`

Deploy: upload `index.html` + `assets/` to the subdomain document root (cPanel File Manager or FTP).
